# 넣어야 할 원자료

분석 스크립트(98·110~131)를 처음부터 돌릴 때만 필요합니다. 보고서만 다시 만들 때(129 → 130)는 필요하지 않습니다.

| 파일 | 위치 | 내용 |
|---|---|---|
| `lending_club_2020_train.csv` | **저장소 맨 위**(README.md와 같은 폴더) | 과제 제공 학습 자료, 1,755,295행 |
| `lending_club_2020_test.csv` | 저장소 맨 위 | 과제 제공 시험 자료, 1,170,198행 |
| `rejected_2007_to_2018Q4.csv` | 저장소 맨 위 | 거절 신청 자료(표본 대표성 진단용). 공개 저장소 marunn00/lendingclub-rejected-data의 Releases에서 받을 수 있음 |

FRED 금리 원자료는 `산출물/raw_macro/`에 이미 들어 있습니다(131번 스크립트는 없는 계열만 내려받음).
