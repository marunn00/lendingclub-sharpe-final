# LendingClub 대출 승인 전략: 최종 보고서와 재현 자료

승인한 대출과 거절한 자금(국채)으로 이루어진 포트폴리오의 Sharpe ratio를 최대로 만드는 대출 승인 전략을 만들고, 팀 공유 보고서·우수사례·채권 형식의 잣대 9개로 같은 기준에서 비교한 최종 보고서와 그 재현 자료입니다. 서울대학교 ABS 과정 14기 통계 & 데이터사이언스 python 실습(LendingClub 팀 프로젝트).

- **최종보고서_논문형.pdf** (22쪽): 같은 분석을 학술 논문 형식(서론 · 연구 방법 · 연구 결과 · 논의 및 결론)으로 다시 쓴 판. 표 32개 · 그림 12개 · 식 20개, 표 CSV는 `산출물/최종보고서/보고서표_논문형/`
- **최종보고서_v4.pdf** (61쪽): 1계조건(FOC) 규칙 중심. 아이디어·설계(A) → 소표본 Ridge·Lasso(B) → ROC·소프트마진(C) → FOC 구현(D) → 교수님 강조 항목(E, E-4 = 대출을 채권처럼 가격 매기기) → 상세 검증(F) → 결론(G, 맨 마지막). 새 표 F1~F31, 그림 F1~F7
- **최종보고서.pdf** (39쪽): 통계청 보도자료 형식. 표지만 읽어도 결론과 근거 수치를 찾을 수 있게 구성
- **활용가이드.pdf** (8쪽): 이 저장소를 쓰는 법, 돌리는 법, 표 42개를 하나씩 설명하는 법

## 결과 요약

| 항목 | 값 |
|---|---|
| 과제 정의 포트폴리오 Sharpe (시험 744,608건) | **0.146** [95% 구간 0.132~0.161, 발급월 군집] |
| 비교: 전부 승인 / 부도확률 순위 | −0.113 / 0.065 |
| 승인율 | 26% (학습 교차검증에서 Sharpe 최대) |
| 9개 잣대 종합 | 5개 우세 · 1개 동등 · 2개 혼재 · 1개 열세 |

공개한 불리한 결과:
- **시간 외 검증(2017~20년 발급분)**: 같은 승인율 6.4%에서 −0.029 (팀 Sharpe 보고서 0.001)로 열세
- **발급 시기 집중**: 매달 같은 비율을 승인하면 Sharpe가 0.051로 낮아짐(부도확률 순위 0.027). 개선의 상당 부분이 대출을 내주는 시기의 선택에서 나옴
- **사후 변경**: 모형 v2·v3와 승인율 26%는 시험 채점 이후에 착안한 변경이며, 학습 자료로만 채택을 판정했고 경위를 부록 4(보고서 표 40)에 기록

## 빠른 시작

### 1. 읽기만 할 때
`최종보고서.pdf` 전체 → `산출물/최종보고서/보고서표/표_설명.csv`(표마다 한 문장 설명)

### 2. 표 숫자를 가져다 쓸 때
| 위치 | 내용 |
|---|---|
| `산출물/최종보고서/보고서표/표NN_*.csv` | 보고서에 실린 표 42개를 **보이는 그대로** 저장한 CSV |
| `산출물/최종보고서/보고서표/표_색인.csv` | 표 번호·제목·열·행 수·주·자료 |
| `산출물/최종보고서/보고서표/표_설명.csv` | 표별 보여주는 것·읽는 법·발표 한 문장·주의 |
| `산출물/최종보고서/표/*.csv` | 분석 단계의 숫자 원본(소수 그대로) |
| `산출물/최종보고서/fig/*.png` | 보고서 그림 15개 |

### 3. 보고서만 다시 만들 때 (원자료 불필요)
```bash
pip install -r requirements.txt
python3 scripts/129_final_figs.py      # 표/*.csv → fig/*.png
python3 scripts/130_final_report.py    # → 산출물/최종보고서/최종보고서.html, 보고서표/*.csv
```
HTML을 브라우저로 열어 A4로 인쇄하면 PDF가 됩니다(배경 그래픽 켜기). 활용가이드는 `python3 scripts/133_guide.py`로 만듭니다.

### 4. 분석을 다시 돌리거나 조건을 바꿀 때 (원자료 필요)
과제 제공 원자료 두 파일을 저장소 맨 위에 두고(`data/README.md`) 보고서 표 41의 순서로 실행합니다.

```text
98·110 → 117 → 124·125 → 121 → 119·116·111 → 126 → 127 (인자 2015, 2016) → 128 → 131 → 129 → 130
```
바꿀 수 있는 조건(승인율, 무위험수익률, 비용, 승인 규칙, 점수, 학습 목표, 시간 외 구간)과 그 위치는 `활용가이드.pdf` 2장 C에 있습니다. 1계조건(분산 한계기여) 승인 규칙을 같은 예측에 적용한 예시는 `scripts/132_lam_rule_experiment.py`입니다. 이 실험은 보고서 본문에 넣지 않았고, v3 대비 Sharpe 0.1468 대 0.1462로 구간이 0을 포함해 동등했습니다.

## 확인한 것과 하지 않은 것

- 확인함: 이 저장소를 빈 폴더에 복사해 `129 → 130 → 133`을 실행하면 원자료 없이도 끝까지 돌고, 결과 HTML·보고서표 CSV 42개·활용가이드 HTML이 원본과 바이트 단위로 같음. 표 설명 문장의 숫자는 코드가 표 CSV에서 읽어 넣음
- 하지 않음: 선행 단계(가공 테이블·시험 점수 parquet을 만드는 96·98·102번대)를 처음부터 다시 돌려 전체 결과를 재현하는 것. 이 중간 산출물은 용량 때문에 저장소에 없습니다.
- 알려진 한계: 이수용 잣대는 기준선이 0.012~0.013 차이로 근사 재현이며 원인은 확인하지 못했습니다. 보고서 표지의 작성자 칸은 "○조 (조원 이름 기입)"로 비어 있습니다.

## 데이터와 라이선스

과제 원자료(`lending_club_2020_train.csv`, `lending_club_2020_test.csv`)와 거절 신청 자료는 용량과 배포 문제로 저장소에 포함하지 않았습니다. FRED 금리 자료는 공개 자료입니다. 코드의 라이선스는 아직 정하지 않았습니다.
